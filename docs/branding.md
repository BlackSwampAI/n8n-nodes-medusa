# Branding and icon provenance

The packaged SVGs predate this migration. On 2026-09-06, the authoritative `medusajs/medusa` `develop` tree was checked at commit `bda24b9725ac697ec5e8f706b503013e20babf12`: current API-reference branding uses [`logo-icon.png`](https://github.com/medusajs/medusa/blob/bda24b9725ac697ec5e8f706b503013e20babf12/www/apps/api-reference/public/images/logo-icon.png), [`logo-icon-dark.png`](https://github.com/medusajs/medusa/blob/bda24b9725ac697ec5e8f706b503013e20babf12/www/apps/api-reference/public/images/logo-icon-dark.png), and [`favicon.ico`](https://github.com/medusajs/medusa/blob/bda24b9725ac697ec5e8f706b503013e20babf12/www/apps/api-reference/app/favicon.ico).

The packaged files hash to `b5717202f99b5f3a6df2a4c5459973d8e4ede7dd5ef8b985774bb0588d6abd35` (`medusa.svg`) and `52fe92f1aad3acf3883db1985f2d847d7799bbe27e2556879ceea85a19c7a50c` (`medusa.dark.svg`). The current official 40×40 PNG was visually compared and uses the same recognizable dark ring glyph as the scalable 60×60 packaged SVG. Exact byte/vector provenance remains unverified because the current vendor repository exposes PNG/ICO, not an authoritative SVG. Retaining the scalable recognizable glyph avoids inventing, tracing, or reducing the node icon to a low-resolution raster.

This is an independent Black Swamp AI community integration. It is not affiliated with, endorsed by, sponsored by, or maintained by Medusa. The Medusa name and logo belong to their respective owner(s) and are used only to identify compatibility.

The published 0.1.1 tarball contains the referenced nonempty SVG files, but a Creator Portal inspection on 2026-09-06 showed a generic card icon. Portal rendering is therefore a separate unresolved human follow-up, not evidence that npm omitted the assets. Future release qualification must verify both icon variants on contrasting backgrounds and record the exact submitted version plus Creator Portal card version/logo.
